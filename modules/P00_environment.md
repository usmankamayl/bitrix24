# P00 — Окружение и инженерная база

- Оценка: 6–8 часов
- Статус: Не начато
- Зависимости: нет

## Цель
Подготовить воспроизводимое и безопасное рабочее окружение для облачных и коробочных упражнений.

## Облако
- Проверить, что тестовый портал доступен.
- Уточнить доступные REST-методы и тип авторизации.
- Выполнить безопасный диагностический запрос.
- Проверить обработку успешного ответа и ошибки.
- Не вставлять секретный webhook URL в репозиторий, скриншоты или историю чата.

## Коробка
- Уточнить версию Bitrix24 и PHP.
- Определить безопасный доступ к тестовому стенду и логам.
- Изучить структуру `/local`, не меняя ядро.
- Подключить минимальный собственный PHP-класс из `/local` способом, подходящим версии и проекту.

## Git
- Инициализировать репозиторий.
- Проверить `.gitignore`.
- Убедиться, что `.env`, токены, пароли и секретные вебхуки не попадают в коммит.
- Создать README с шагами воспроизведения.

## Практические шаги
1. Уточнить версии/доступы.
2. Проверить Git и `.gitignore`.
3. Выполнить один REST-запрос к облаку.
4. Разобрать намеренно некорректный запрос без публикации секретов.
5. На коробке подключить тестовый класс из `/local`.
6. Зафиксировать результаты и отличия облака/коробки.

## Критерии приёмки
- [ ] Версии и окружение описаны.
- [ ] REST-запрос выполнен, результат понятен.
- [ ] Ошибка REST разобрана.
- [ ] Класс подключается на коробке.
- [ ] Первый коммит создан.
- [ ] Секреты не попали в Git.
- [ ] Различия облака и коробки записаны.

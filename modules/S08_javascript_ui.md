# S08 — JavaScript и UI

- Оценка: 6–8 часов
- Статус: Не начато
- Зависимости: S06

## Цель
В начале занятия сформулировать измеримый результат.

## Облачная дорожка
Поддерживаемые способы UI-интеграции без раскрытия секретов в браузере.

## Коробочная дорожка
BX JS, расширения, AJAX/контроллеры и серверная проверка прав.

## Практическая задача
Панель статуса и действие повторной отправки без двойного запуска.

## Порядок работы
1. Уточнить версии, права и доступные методы, если они влияют на решение.
2. Описать поток данных и границы ответственности.
3. Реализовать минимальный рабочий сценарий.
4. Проверить негативные случаи, права и повторный запуск.
5. Записать результаты и ограничения.

## Критерии приёмки
Права проверяются сервером; UI показывает ожидание/ошибки; повтор безопасен.

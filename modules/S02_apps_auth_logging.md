- Оценка: 10–14 часов
- Статус: Реализовано (не проверено)
- Зависимости: S01

## Цель
В начале занятия сформулировать измеримый результат.

## Облачная дорожка
Модель приложения/OAuth, установка и переустановка, изоляция порталов, жизненный цикл токенов.

## Коробочная дорожка
Конфигурация установки, параметры окружения, настройки модуля и структурированные логи.

## Практическая задача
Разделить dev/test, добавить диагностику с маскированием чувствительных данных.

## Порядок работы
1. Уточнить версии, права и доступные методы, если они влияют на решение.
2. Описать поток данных и границы ответственности.
3. Реализовать минимальный рабочий сценарий.
4. Проверить негативные случаи, права и повторный запуск.
5. Записать результаты и ограничения.

## Критерии приёмки
Нет смешения окружений/порталов; чувствительные значения маскируются; есть runbook.

## Результат занятия

### Облако
- OAuth 2.0 модель задокументирована (см. `.claude/docs/cloud-oauth-guide.md`)
- Жизненный цикл токенов, изоляция порталов, установка/переустановка
- Примеры кода для TokenManager
- **Требует облачного портала для проверки** — отложено до наличия SaaS-доступа

### Коробка
- ✓ Управление окружениями (dev/test/prod)
- ✓ Конфигурационный файл `environments.php`
- ✓ Класс `Environment` для получения параметров
- ✓ Структурированное логирование с маскированием
- ✓ Класс `Logger` с автоматическим маскированием чувствительных данных
- ✓ Диагностический скрипт `check_config.php`

### Файлы/коммиты
- `box/local/php_interface/config/environments.php` — настройки окружений
- `box/local/php_interface/config/.environment` — текущее окружение (не в git)
- `box/local/php_interface/config/.environment.example` — пример
- `box/local/classes/Training/Config/Environment.php` — класс управления
- `box/local/classes/Training/Config/Logger.php` — структурированное логирование
- `box/tests/test_environment.php` — тесты окружения
- `box/tests/test_logger.php` — тесты логирования
- `box/diagnostics/check_config.php` — диагностика конфигурации
- `.claude/docs/cloud-oauth-guide.md` — теория OAuth для облака

### Фактические проверки
1. ✓ Переключение окружений (dev → test → dev)
2. ✓ Получение параметров через `Environment::get()`
3. ✓ Маскирование паролей, токенов, API ключей
4. ✓ Проверка безопасности: секреты не попадают в логи
5. ✓ Различные уровни логирования (debug/info/warning/error)
6. ✓ Диагностический скрипт проверяет окружение

### Ошибки/ограничения
- Облачная часть — только документация, требует SaaS-портала
- SSH-доступ к серверу не настроен (проверки выполнялись локально)

### Решения
- Класс `Environment` — централизованное управление окружениями
- Класс `Logger` — автоматическое маскирование по списку SENSITIVE_KEYS
- Файл `.environment` в `.gitignore` — защита от случайного коммита
- Диагностический скрипт — быстрая проверка корректности настроек

## Важные выводы P00 (запомнить!)

### REST API vs D7 API
**Коробка:**
- Основной способ — **D7 API** (прямая работа с классами)
- REST API используется только для внешних интеграций
- Пример: `\Bitrix\Main\UserTable::getById(1)->fetch()`

**Облако:**
- Основной способ — **REST API** (HTTP, вебхуки, OAuth)
- Нет прямого доступа к файлам и PHP-классам портала
- Пример: `POST https://portal.bitrix24.ru/rest/user.current`

### Структура `/local`
```
/local/
  php_interface/init.php  ← автозагрузка, события
  classes/                ← пользовательские классы
  modules/                ← пользовательские модули
```

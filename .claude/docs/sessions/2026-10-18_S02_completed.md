# Сессия 2026-10-18: Модуль S02 — Приложения, окружения, авторизация и логирование

## Цель модуля
Освоить управление окружениями, OAuth-приложения в облаке, конфигурацию в коробке и структурированное логирование с маскированием.

## Что реализовано

### Коробочная часть (проверено)

#### 1. Управление окружениями
- Класс `Training\Config\Environment`
- Конфигурационный файл `environments.php` (dev/test/prod)
- Файл `.environment` для переключения окружения (не в git)
- Методы: `getCurrent()`, `isDev()`, `get('key.nested')`

**Проверено:**
- ✓ Переключение dev → test → prod
- ✓ Получение вложенных параметров через точечную нотацию
- ✓ Значения по умолчанию для несуществующих ключей

#### 2. Структурированное логирование
- Класс `Training\Config\Logger`
- Уровни: debug, info, warning, error
- Автоматическое маскирование чувствительных данных
- JSON-формат записей
- Привязка к уровню логирования окружения

**Проверено:**
- ✓ Маскирование паролей, токенов, API ключей, вебхуков
- ✓ Чувствительные данные не попадают в логи (проверка через grep)
- ✓ Уровни логирования фильтруют сообщения

#### 3. Диагностический скрипт
- `box/diagnostics/check_config.php`
- Проверяет окружение, конфигурацию, файловую систему, логирование
- Выявляет критические ошибки и предупреждения

**Проверено:**
- ✓ Обнаруживает включённый debug в production
- ✓ Предупреждает об отключённой SSL verification
- ✓ Тестирует маскирование секретов

## Ключевые решения

### Разделение окружений
Каждое окружение имеет свои параметры:
- `debug` — включение отладочного режима
- `log_level` — уровень логирования
- `external_api` — настройки внешних интеграций (timeout, SSL, base_url)

Файл `.environment` не коммитится — каждый сервер имеет своё окружение.

### Маскирование секретов
Автоматически маскируются любые ключи, содержащие:
- password, token, secret, api_key, auth, webhook, private_key

Формат маскирования: показываем первые 2 и последние 2 символа, остальное — звёздочки.

### Структура логов
JSON-формат для машинной обработки:
```json
{
  "timestamp": "2026-10-18 22:37:35",
  "level": "INFO",
  "message": "API запрос",
  "context": {...},
  "environment": "dev"
}
```

3. **Bitrix D7 не загружен** — использованы standalone классы

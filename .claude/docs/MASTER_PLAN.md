# Мастер-план обучения Bitrix24

## Профиль
PHP и JavaScript знаю; Bitrix24 — начальный уровень; облако: простые REST-запросы и вебхуки; есть тестовая коробка. Цель — самостоятельная разработка для обеих версий.

Оценка: 130–190 часов, ориентировочно.

## Сквозной проект
B2B-сервисные заявки: создание → диагностика → согласование → внешний заказ → результат в Bitrix24.

## Критерии готовности каждого модуля
- Цель и архитектура объяснены.
- Облачный и коробочный пути описаны отдельно.
- Реализация проверена на доступном тестовом окружении или ограничение явно оформлено.
- Негативные сценарии и права проверены.
- Изменения зафиксированы в Git.
- Есть короткая документация и следующий шаг.

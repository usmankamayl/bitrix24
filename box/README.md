# Box implementation

Здесь хранятся учебные исходники для коробочного Bitrix24. Для развёртывания в реальной коробке обычно нужен отдельный путь/репозиторий и подтверждённая версия. Не коммитить ядро, секреты или production-конфигурацию. В коробке предпочитать `/local` и поддерживаемые точки расширения.

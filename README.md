# Bitrix24 Training for Claude Code

Учебный репозиторий для пошагового освоения разработки Bitrix24 в облаке и коробке.

## Требования
- Git.
- Claude Code, установленный и авторизованный по официальной инструкции Anthropic.
- PHP/Node.js нужны только если они требуются для конкретных практик.
- Доступ к тестовому облачному порталу и коробке — для реальных интеграционных проверок.

## Быстрый старт
1. Распакуйте архив в рабочую папку.
2. Инициализируйте Git, если это ещё не репозиторий:
   ```bash
   git init
   git add .
   git commit -m "chore: initialize Bitrix24 training workspace"
   ```
3. Откройте терминал в корне проекта и запустите Claude Code командой `claude` (если он установлен).
4. В Claude Code попросите: `Начни учебную сессию. Следуй CLAUDE.md и начни с P00.`
5. Claude должен прочитать только основные файлы состояния и текущий модуль.

## Контекстная дисциплина
- `CLAUDE.md` — постоянные правила проекта.
- `docs/MASTER_PLAN.md` — вся программа; читается при необходимости, а не на каждом шаге.
- `docs/PROGRESS.md` — текущие статусы.
- `docs/HANDOFF.md` — компактная передача состояния.
- `modules/` — отдельные учебные модули.
- `docs/sessions/` — короткие записи после занятий.
- `docs/decisions/` — важные архитектурные решения.

## Работа с облаком и коробкой
Не храните секреты в репозитории. Используйте локальные переменные окружения или локальные файлы конфигурации, исключённые из Git. Не вставляйте секретные URL вебхуков в отчёты, логи или сообщения.

## Что ещё нужно настроить вручную
Этот архив не подключает Bitrix24 к Claude автоматически. Доступ к порталам, MCP, тестовой коробке, SSH и внешним системам нужно настраивать отдельно и безопасно. Не считайте MCP подключённым, пока соединение не проверено.
